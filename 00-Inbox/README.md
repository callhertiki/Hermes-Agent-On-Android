# 00-Inbox

> Everything unprocessed lands here. Nothing lives here permanently.

---

## Rules

- Drop any raw capture here when you don't know where it belongs yet
- Process this folder every evening (move items to correct folders)
- Nothing stays here more than 48 hours
- If an item has no clear home, ask Mea Kākau where it belongs

---

## Processing Checklist

Run this when clearing the Inbox:

- [ ] Read each item
- [ ] Decide: Learn / Research / Project / Cybersecurity / Discord / Archive / Delete
- [ ] Move to correct folder
- [ ] Add tags and date if missing
- [ ] Link to any related notes

---

## Quick Drop Template

Use this format when dropping something fast:

```
**Captured:** [DATE TIME]
**Source:** [where it came from]
**Content:** [the thing]
**Why:** [why I saved it]
```
