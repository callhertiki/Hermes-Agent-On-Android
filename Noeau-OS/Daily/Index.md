## How to Use

1. Each morning, create a new note from [[../Templates/Daily-Note|Daily Note Template]]
2. Name it `YYYY-MM-DD` (e.g. `2025-01-15`)
3. Complete the morning section to set your day
4. Return in the evening to close the loop
5. Link the note below under the right week
