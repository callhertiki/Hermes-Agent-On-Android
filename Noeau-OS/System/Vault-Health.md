## How to Run an Audit

1. In Obsidian, open **Settings → Files & Links** to check link behavior
2. Use the **Backlinks** panel to check for orphaned notes
3. Install or use the **Vault Statistics** plugin if available
4. Open **Settings → Community Plugins** and check for outdated plugins
5. Verify your backup solution has run recently
6. Paste your findings into [[../Agents/Kiai|Kiaʻi's Prompt Block]] for a full analysis
