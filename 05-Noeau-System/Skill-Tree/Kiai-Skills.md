# Kiaʻi — Skill Tree

> Track your security and system protection skills. These protect everything else you build.

---

## How to Use

- `[ ]` Not started / `[~]` In progress / `[x]` Consistent

---

## Tier 1 — Aware

*Goal: Know what good digital hygiene looks like*

- [ ] Back up the Obsidian vault manually at least once (Git push or file copy)
- [ ] Enable 2FA on all accounts with sensitive data (email, GitHub, bank)
- [ ] Use a password manager — no reused passwords
- [ ] Know what a phishing email looks like and identify one example
- [ ] Understand the difference between HTTP and HTTPS

---

## Tier 2 — Practiced

*Goal: Make good security a habit, not a task*

- [ ] Set up automatic vault backup (scheduled Git commit or cloud sync)
- [ ] Run a monthly security checklist consistently for 3 months
- [ ] Understand the CIA triad (Confidentiality, Integrity, Availability)
- [ ] Know what a firewall does and why it matters
- [ ] Identify the 5 most common types of cyberattacks (phishing, malware, MITM, etc.)

---

## Tier 3 — Defensive Practitioner

*Goal: Actively harden systems and recognize threats*

- [ ] Understand the OSI model and which attacks target which layers
- [ ] Set up and review system logs (Windows Event Viewer or Linux syslog)
- [ ] Know how to respond to a compromised account (steps 1–5)
- [ ] Understand basic network scanning (what nmap does and why)
- [ ] Complete one beginner CTF challenge (TryHackMe or HackTheBox)

---

## Tier 4 — Security Mindset

*Goal: Think offensively to defend defensively*

- [ ] Understand common web vulnerabilities: XSS, SQLi, CSRF, IDOR
- [ ] Complete a beginner web security room on TryHackMe
- [ ] Write a personal incident response plan for top 3 threat scenarios
- [ ] Conduct a basic security audit of your own systems
- [ ] Understand what a penetration test is and its legal boundaries
