# Builder — Skill Tree

> Track your ability to plan, build, and ship projects from idea to done.

---

## How to Use
- `[ ]` Not started / `[~]` In progress / `[x]` Consistent

---

## Tier 1 — Idea Maker
- [ ] Turn a vague idea into a one-sentence project goal
- [ ] List what a project needs vs. what would be nice to have
- [ ] Define what "done" looks like for a small project before starting
- [ ] Break any goal into 3 steps you could do today
- [ ] Create a project note using the Project Note Template

## Tier 2 — Milestone Planner
- [ ] Define an MVP (Minimum Viable Product) for a project — smallest version that proves the idea
- [ ] Break a project into 3–5 phases with specific deliverables
- [ ] Identify the one biggest risk or blocker for a project
- [ ] Complete a small project (anything) from concept to working result
- [ ] Write a project retrospective: what worked, what didn't, what's next

## Tier 3 — Consistent Builder
- [ ] Complete 3 projects from idea to shipped result
- [ ] Estimate task time and track how close you were (calibrate estimation)
- [ ] Identify when a project has scope creep and cut it
- [ ] Document a project well enough that someone else could continue it
- [ ] Manage a project that involves research + building + writing (all three)

## Tier 4 — Shipping Machine
- [ ] Complete a project with 3+ milestones and 20+ tasks
- [ ] Build something that other people use or benefit from
- [ ] Run a full project lifecycle: plan → build → review → improve → repeat
- [ ] Teach project management principles to someone else from your own practice
- [ ] Complete a technical project in a domain you didn't know before starting
