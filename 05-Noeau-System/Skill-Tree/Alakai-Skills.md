# Alakaʻi — Skill Tree

> Track your planning, goal-setting, and self-accountability skills.

---

## How to Use
- `[ ]` Not started / `[~]` In progress / `[x]` Consistent

---

## Tier 1 — Basic Planner
- [ ] Write a daily note with Top 3 priorities every morning for 1 week straight
- [ ] Complete the evening close-out section of a daily note at least 3 times
- [ ] Write a goal that has a deadline and a specific outcome (not "learn Python")
- [ ] Identify one recurring avoidance pattern in your day and name it
- [ ] Finish a planned task instead of switching to something easier mid-session

## Tier 2 — Consistent Planner
- [ ] Complete daily notes 5 days in a row (morning + evening)
- [ ] Run a weekly review 3 weeks in a row
- [ ] Write goals that pass the SMART test (Specific, Measurable, Achievable, Relevant, Timed)
- [ ] Identify your peak focus hours and schedule deep work there
- [ ] Track a 2-week habit using a simple log

## Tier 3 — Strategic Thinker
- [ ] Build a 90-day goal map with milestones
- [ ] Complete a monthly review that informs the next month's priorities
- [ ] Reduce recurring avoidance behavior by name (evidence: it stopped showing in logs)
- [ ] Design a weekly schedule template that reflects your real energy patterns
- [ ] Identify when a goal needs to be dropped vs. paused vs. persisted

## Tier 4 — Execution System Owner
- [ ] Run daily + weekly reviews consistently for 90 days
- [ ] Achieve a stated 90-day goal from planning to completion
- [ ] Build a personal operating system (templates, reviews, goal tracking all connected)
- [ ] Teach your planning system to someone else
- [ ] Run a quarterly review and update long-term goals based on evidence
