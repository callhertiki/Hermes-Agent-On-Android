# Kumu — Skill Tree

> Track your ability to teach, explain, and structure knowledge. Mark each skill when you can do it consistently without looking it up.

---

## How to Use

- `[ ]` Not started
- `[~]` In progress
- `[x]` Can do it consistently

Level up when 80% of a tier is complete before moving to the next.

---

## Tier 1 — Novice Teacher

*Goal: Explain what you're learning clearly to yourself*

- [ ] Write a plain-language summary of any topic I just studied
- [ ] Identify what I don't understand (and name it specifically)
- [ ] Use the Feynman technique: explain a concept as if teaching a 12-year-old
- [ ] Format a note with clear H1/H2 headings and bullet points
- [ ] Write 3 review questions for any topic I studied

---

## Tier 2 — Structured Explainer

*Goal: Build lessons others could follow*

- [ ] Create a complete lesson using Overview → Concepts → Examples → Practice → Summary
- [ ] Design a 5-step learning path for a topic from zero to functional
- [ ] Write a Discord-ready lesson note (under 1800 characters, clear structure)
- [ ] Build a review session using spaced repetition style questions
- [ ] Identify the most common beginner mistake for any topic

---

## Tier 3 — Curriculum Designer

*Goal: Map learning across multiple topics*

- [ ] Build a full curriculum for one subject (5+ connected lessons)
- [ ] Create prerequisite maps: what must be known before topic X?
- [ ] Design progressive difficulty for a skill (beginner → intermediate → advanced)
- [ ] Write lessons that account for different learning styles
- [ ] Evaluate someone else's explanation for accuracy and clarity

---

## Tier 4 — Master Communicator

*Goal: Teach anything to anyone, at any level*

- [ ] Take a complex technical concept and explain it 3 ways (beginner, intermediate, expert)
- [ ] Build a live workshop or study session structure
- [ ] Create a "common misconceptions" guide for any topic
- [ ] Design assessment questions that reveal real understanding vs. surface familiarity
- [ ] Mentor another learner through a topic from start to functional competence
