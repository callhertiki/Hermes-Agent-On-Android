# Mea Kākau — Skill Tree

> Track your note-making, formatting, and knowledge-organization skills.

---

## How to Use
- `[ ]` Not started / `[~]` In progress / `[x]` Consistent

---

## Tier 1 — Basic Note Maker
- [ ] Write a note with clear title, sections, and bullets
- [ ] Add YAML frontmatter (date, tags) to a new note
- [ ] Summarize a source in 5 bullets or fewer
- [ ] Use `[[double brackets]]` for internal links correctly
- [ ] Save a raw thought to Inbox and process it into the right folder

## Tier 2 — Structured Scribe
- [ ] Convert a messy raw note into clean Obsidian format
- [ ] Create a Discord-ready note under 1800 characters
- [ ] Build a Map of Content (MOC) linking 5+ related notes
- [ ] Break a long note into 3 focused atomic notes
- [ ] Write action steps from any source (specific, not vague)

## Tier 3 — Vault Architect
- [ ] Design a consistent tagging system and apply it across 20+ notes
- [ ] Build a subject index that links all notes in one area
- [ ] Identify and link 10 orphaned notes in one session
- [ ] Create a template others could use to replicate a note type
- [ ] Convert research from 3 different sources into one synthesized note

## Tier 4 — Knowledge Engineer
- [ ] Build a complete knowledge base for one subject (20+ linked notes)
- [ ] Create a "second brain" structure someone else could navigate
- [ ] Design a processing workflow: Inbox → Clean → File → Link → Review
- [ ] Produce Discord content that others actually save and reference
- [ ] Build a personal glossary for a technical domain
