# Mea Huli — Skill Tree

> Track your research, synthesis, and source-management skills.

---

## How to Use
- `[ ]` Not started / `[~]` In progress / `[x]` Consistent

---

## Tier 1 — Active Reader
- [ ] Log a book or article in the reading tracker with title, author, status
- [ ] Write key takeaways for any source (3–5 bullets, specific not vague)
- [ ] Add one quote worth keeping to a research note
- [ ] Identify one gap in your understanding that a source left open
- [ ] Create a research note using the Research Note Template

## Tier 2 — Source Organizer
- [ ] Maintain a reading list with 5+ sources tracked and up to date
- [ ] Rate a completed book and write a 2-sentence honest review
- [ ] Find 2 sources that say different things about the same topic and note the difference
- [ ] Create a research summary that synthesizes 3 sources on one topic
- [ ] Build a reading queue in priority order with reasons

## Tier 3 — Research Synthesizer
- [ ] Write a research overview that combines 5+ sources coherently
- [ ] Find connections between 2 different subjects in your notes
- [ ] Build a "what the evidence says" note on a topic (not your opinion)
- [ ] Identify which of your beliefs about a topic need better sourcing
- [ ] Create a "what I don't know yet" note for any major subject area

## Tier 4 — Knowledge Mapper
- [ ] Build a complete bibliography for a technical subject
- [ ] Create a visual (text-based) concept map linking 10+ ideas
- [ ] Produce a synthesis paper (in notes) from 8+ sources
- [ ] Recommend a reading path for a beginner in any subject you've researched
- [ ] Identify the most important 3 books in a field and justify why
