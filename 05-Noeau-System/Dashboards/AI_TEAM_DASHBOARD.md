## Daily Workflow — Which Agent When

```
MORNING
  └── Alakaʻi — plan the day

STUDY SESSION
  └── Kumu — create lesson / quiz me
  └── Mea Kākau — clean up notes after
  └── Mea Huli — summarize a source

WORK SESSION
  └── Builder — plan tasks / review progress
  └── Alakaʻi — accountability check (every 30 min)

EVENING
  └── Alakaʻi — reflection / what I avoided
  └── Mea Kākau — format Discord notes

WEEKLY
  └── Alakaʻi — weekly review
  └── Kiaʻi — system + backup audit
  └── Mea Huli — reading list review
```
