| 4 | Master | Fluent — this is part of your operating system |

## How to Level Up

1. Work through the skills in the current tier (mark `[x]` when consistent, not just done once)
2. When 80% of a tier is marked `[x]`, you've leveled up
3. Update the table above with new level + date
4. Move to the next tier
