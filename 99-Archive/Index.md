# 99-Archive — Index

> Completed notes, retired content, and anything no longer active. Nothing is deleted — it comes here.

---

## Archive Rules

1. Never delete a note — move it here instead
2. Rename with date: `[note-name]-YYYY-MM-DD.md`
3. Add a one-line reason for archiving in the note's frontmatter
4. If a note was wrong or outdated, note that explicitly

## How to Restore

1. Open it here
